# Shlok — Personal portfolio

A story-led portfolio built with Next.js App Router, React, TypeScript, Sass, GSAP, Three.js, and Framer Motion. The root page is an original interactive vinyl-inspired introduction; its entry links lead into the five portfolio chapters: Signal (`/portfolio`), Foundation, Setu, Horizon, and Connection. The experience uses an editorial dark direction, an optimized portrait supplied by Shlok, and an original GLSL-shaded 3D centerpiece on the Horizon page with a CSS fallback.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, then serve it with `npm start`.

## Content notes

The site uses only the supplied personal facts. The Setu repository could not be opened during research, so the project description stays at the level of the supplied brief and the abstract diagram is labeled as conceptual. No project screenshots, testimonials, metrics, or logos are included. The portrait on the Signal page is the supplied image, optimized as WebP for display. The vinyl is an original CSS illustration that rotates continuously; licensed user-provided intro music plays only after the visitor activates the audio button. Reduced-motion preferences disable decorative animation. The references Two26 Studio and Ascension informed broad art-direction choices; the layout, content, and artwork are original. Mild Sugar Design was inaccessible, so its supplied art-direction notes informed the visual hypothesis.
